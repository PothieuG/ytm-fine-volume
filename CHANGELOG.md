# Changelog

## 1.4.0 (2026-10-13)

First public release on [addons.mozilla.org](https://addons.mozilla.org/firefox/addon/fine-volume-for-youtube-music/).

- Volume curve (`volume^k`, k = 2 by default, adjustable from 1 to 3). The quietest level drops from −40 dB to −80 dB, and YouTube Music's loudness normalization stays linear.
- 1 % steps with the mouse wheel over the player bar and the ↑ / ↓ arrow keys, with a short on-page display.
- Toolbar popup styled like YouTube Music:
  - type the exact volume, use − / + or the slider, and see the actual output level in dB;
  - an Active / Inactive badge, with a one-click fix when the extension can't act (reload the tab, allow access, open YouTube Music);
  - collapsible settings.
- English and French interface.
- Requires Firefox 142 or later (desktop only).

Versions 1.0.0 to 1.3.0 were private development builds.
